Sends to every dial

Steers Sensor Dial actions from any key, pedal, G-key or Multi Action step, on this or another Stream Deck. The key shows a tick when the command reached at least one dial and an alert when none matched.

Command

"Every dial, everywhere" ignores the Target and clears session stats on all dials, on all Stream Decks, including hidden ones.

Leave empty to steer every dial, or type a Link ID (set on a dial under Controls) to steer only the dials that carry it.

AdvancedSupport report

Copies a redacted diagnostics report (devices, data source, action states; no sensor values, no names) to the clipboard. Nothing is uploaded.
