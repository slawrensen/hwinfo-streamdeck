How Display works

Overviews list what rotation moves through: the rotation set, the active group, or the picked sensor's readings. Three rows mark the reading on the dial with a thumb on the left rail; two rows trade a row for big values and a trend line. The bar range applies to the one-reading view.

Color numbers by sensor type is off by default; Paper and unknown sensor types keep normal text. Reading colors give each reading its own number color, independent of type accents, that follows it through rotation. A custom text color overrides them and Dimmed dims them; alerts keep priority and graphs stay unchanged.

Alerts

Warn, Critical and the bar ends apply only to readings in the unit that was on the dial when you last changed any of them, so a temperature limit never fires on a fan. The dial stays themed; the bar, or an overview row's value, takes the alert color. Alerts check the current value in the reading's own unit (°F when °F is on); for bytes and rates that is HWiNFO's number and unit, which the dial may show rescaled.

Controls

Two zones split the strip into previous and next, so the tap command (Touch tap in Custom, stat cycling in Elite) no longer fires. Three keeps a center tap.

Auto cycle steps through the rotation (or the picked sensor's readings) on a timer, even while turns are ignored.

HWiNFO Control keys whose Target is this name steer this dial, from any key, pedal or Multi Action.

How the presets work

Legacy: turn cycles readings (pressed or not), push resets session stats, touch cycles the stat, long touch returns to the current value. Elite: turn cycles readings in the rotation, pressed turn jumps to the next group (or sensor), short push pauses the auto cycle, long push resets stats. Switching from Elite to Custom copies the Elite map into the choices, so you change only the gesture you want different.

HWiNFO setup steps
  1. Install and start HWiNFO (hwinfo.com) in Sensors-only mode.
  2. In HWiNFO Settings, enable Shared Memory Support. On the free version you can instead click Configure Sensors in the sensor window, open the HWiNFO Gadget tab, tick Enable reporting to Gadget, then tick "Report value in Gadget" on the readings you want (no 12-hour limit).
  3. Pick a reading under Reading.
Support

Copies a redacted diagnostics report (devices, data source, action states; no sensor values, no names) to the clipboard. Nothing is uploaded.

Configuration documents

The exact settings as JSON: Copy one to back a dial up, paste a saved one and Replace to restore or clone it. Replace swaps the whole document, reloads this panel and keeps fields this version does not know. Replacing shared settings changes every HWiNFO key and dial and asks for a second click.
