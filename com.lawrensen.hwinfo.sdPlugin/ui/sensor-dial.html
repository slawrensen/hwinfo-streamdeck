Reading

Turning the dial changes this too. Arrow keys browse, Enter picks, Tab or a click elsewhere closes without changing anything.

Rotation

Ticking adds a reading; it never changes what is on the dial now. On each reading, the arrows set their order. Down Arrow moves into the list, arrows move inside it, Tab leaves it.

Rotation groups need a gesture that can switch groups, and this dial's control map has none. Set Controls to Elite, or map a gesture to "Switch sensor or group" in Custom.

Display

Overviews list what rotation moves through: the rotation set, the active group, or the picked sensor's readings. Three rows mark the reading on the dial with a thumb on the left rail; two rows trade a row for big values and a trend line.

Off by default; needs Text color on Theme text or Dimmed, with Accent colors by sensor type. A valid custom text color overrides it, alerts keep priority, and Paper and unknown sensor types keep normal text.

A color for each reading, independent of type accents, that follows it through rotation. A custom text color overrides these colors and Dimmed dims them; alerts keep priority and graphs stay unchanged.

Theme

Pick a theme for this dial, or Default to follow the shared theme.

Colors the numbers and labels. An alerting value keeps its warn or critical color. The bar and selection marks take the accent color instead.

One-reading view only. Blank ends follow the session low and high.

Alerts

Use the live reading's number, in °F when °F is on; for bytes and rates, HWiNFO's original number and unit, before Data units rescales them. Thresholds apply only to readings in the unit that was on the dial when you set them, so a temperature limit never fires on a fan. The dial stays themed; the bar, or an overview row's value, takes the alert color.

Controls

Legacy: turn cycles readings (pressed or not), push resets session stats, touch cycles the stat, long touch returns to the current value. Elite: turn cycles readings in the rotation, pressed turn jumps to the next group (or sensor), short push pauses the auto cycle, long push resets stats.

Switching from Elite to Custom copies the Elite map into the choices below, so you change only the gesture you want different.

Two zones split the strip into previous and next, so the tap command (Touch tap in Custom, stat cycling in Elite) no longer fires. Three keeps a center tap.

Auto cycle steps through the rotation (or the picked sensor's readings) on a timer, even while turns are ignored.

HWiNFO setup steps
  1. Install and start HWiNFO (hwinfo.com) in Sensors-only mode.
  2. In HWiNFO Settings, enable Shared Memory Support. On the free version you can instead click Configure Sensors in the sensor window, open the HWiNFO Gadget tab, tick Enable reporting to Gadget, then tick "Report value in Gadget" on the readings you want (no 12-hour limit).
  3. Pick a reading under Reading.
Support

Copies a redacted diagnostics report (devices, data source, action states; no sensor values, no names) to the clipboard. Nothing is uploaded.

Configuration documents

The exact settings as JSON. Copy one to back a dial up; paste a saved document and Replace to restore or clone it. Replace swaps the whole document, reloads this panel, and keeps fields this version does not know. Replacing shared settings changes every HWiNFO key and dial and asks for a second click.
