Reading

Type part of a reading or sensor name. Arrow keys browse, Enter picks, Tab or a click elsewhere closes without changing anything.

This layout draws once another reading is picked below. Until then the key shows one reading.

A press cycles both rows unless row 2 is pinned to one stat (a minimum and maximum pair). The accent follows reading 1.

A long name shortens so its number stays whole. Every row shows the same stat.

Display

Numbers and labels. Graphs, bars and stat badges use the accent color; warn and critical colors always win.

Temperature

Spans 0 to 100 for percentages and 0 to 1 for Yes/No readings, otherwise the observed range (Shared Memory: HWiNFO's session min and max; Gadget: the last 36 samples), with amber and red zones at your alert thresholds.

How Display works

Pressing the key cycles current → min → max → avg. Shared Memory gives HWiNFO's own minimum, maximum and average since it started; Gadget publishes none, so they show N/A.

Alerts

At or past Warn the key turns amber, at or past Critical red. Alerts check the current value in the reading's own unit (°F when °F is on); for bytes and rates that is HWiNFO's number and unit, which the key may show rescaled. Only reading 1 is checked; it recolors the whole key.

How the detail view works

Tiles use the same faces as keys. Pressing a tile cycles the stat for all its readings. A custom list can group its tiles one by one.

Details open as a plugin-managed profile: the deck switches to a bundled one-page view whose top-left Back tile returns you here. Previous and Next page through long lists.

HWiNFO setup steps
  1. Install and start HWiNFO (hwinfo.com) in Sensors-only mode.
  2. In HWiNFO Settings, enable Shared Memory Support. On the free version you can instead click Configure Sensors in the sensor window, open the HWiNFO Gadget tab, tick Enable reporting to Gadget, then tick "Report value in Gadget" on the readings you want (no 12-hour limit).
  3. Pick a reading under Reading.
Support

Copies a redacted diagnostics report (devices, data source, action states; no sensor values, no names) to the clipboard. Nothing is uploaded.

Configuration documents

The exact settings as JSON: Copy one to back a layout up, paste a saved one and Replace to restore or clone it. Replace swaps the whole document, reloads this panel and keeps fields this version does not know. Replacing shared settings changes every HWiNFO key and dial and asks for a second click.
