This is the Back tile of the sensor detail view. Set its reading, layout and look like any key; pressing it always returns to the profile you came from, so press settings do not apply here.

    Temperature
    Unit and decimals per reading

    A unit picked here stays at any value.

    Spans 0 to 100 for percentages and 0 to 1 for Yes/No readings, otherwise the observed range (Shared Memory: HWiNFO's session min and max; Gadget: the last 36 samples), with amber and red zones at your alert thresholds.

    How Display works

    Pressing the key cycles current → min → max → avg. Shared Memory gives HWiNFO's own minimum, maximum and average since it started; Gadget publishes none, so they show N/A.

    Alerts

    At or past Warn the key turns amber, at or past Critical red. Bytes and rates use HWiNFO's number and unit, even where the key shows another. These are reading 1's unless a row below gives it its own; the key takes the highest level.

    Press

    This Back tile always returns to the previous profile when pressed. Press settings stored on it are kept, unused.

    The first time details open on each kind of deck, Stream Deck asks to install the bundled detail view (and again after an update that changes it).

    Tick readings to add or remove them. The tiles below keep their order; the arrow buttons move them. Down Arrow moves into the list, arrows move inside it, Tab leaves it.

    Matches sensor name and label together, across every sensor. Plain text matches anywhere; * spans anything, ? one character, and | adds another pattern (*gpu*fan* | pump).

    How the detail view works

    Tiles use the same faces as keys. Pressing a tile cycles the stat for all its readings. A custom list can group its tiles one by one.

    Details open as a plugin-managed profile: the deck switches to a bundled one-page view whose top-left Back tile returns you here. Previous and Next page through long lists.

    HWiNFO setup steps
    1. Install and start HWiNFO (hwinfo.com) in Sensors-only mode.
    2. In HWiNFO Settings, enable Shared Memory Support. On the free version you can instead click Configure Sensors in the sensor window, open the HWiNFO Gadget tab, tick Enable reporting to Gadget, then tick "Report value in Gadget" on the readings you want.
    3. Pick a reading under Reading.
